[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**metal-KANs**: библиотека сетей Колмогорова-Арнольда (**Kolmogorov-Arnold Networks, KAN**) на чистом **Metal Shading Language (MSL)** для Apple Silicon (M1 / M2 / M3 / M4 / Pro / Max / Ultra) с удобной Python / NumPy оберткой.

В отличие от стандартных фреймворков глубокого обучения, материализующих трехмерные базисные тензоры в видеопамяти, **metal-KANs вычисляет базис и линейную проекцию GEMM непосредственно в регистрах потоков GPU и разделяемой памяти тредгруппы (SRAM)**.

---

## Ключевые возможности

- **Полный набор из 10 современных архитектур KAN**:
  - `ChebyKAN`: Полиномы Чебышёва 1-го рода (3-термная рекуррентность в регистрах).
  - `FastKAN`: Гауссовы радиальные базисные функции (RBF) с общими центрами.
  - `ReLUKAN`: Кусочно-линейные палаточные функции (ноль трансцендентных операций).
  - `WavKAN`: Непрерывные вейвлеты (Mexican Hat, Morlet, DOG) для частотно-временной локализации.
  - `FourierKAN`: Гармонические тригонометрические ряды ($\cos, \sin$) для периодических процессов и PINN.
  - `JacobiKAN`: Ортогональные полиномы Якоби с весовыми коэффициентами $(\alpha, \beta)$.
  - `RationalKAN`: Дроби Паде-Чебышёва ($P(x) / (1 + |Q(x)|)$) для моделирования полюсов и сингулярностей.
  - `BSplineKAN` / `KAN`: Классический алгоритм Кокса-де Боора для кубических B-сплайнов.
  - `MultKAN`: KAN 2.0 с узлами умножения ($u \cdot v$) для точного моделирования законов сохранения.
  - `LowRankKAN`: Факторизованная проекция (LoRA / Bottleneck) со сжатием параметров до 10 раз.
  - `GatedKAN` (v0.6.0): Дроп-ин замена SwiGLU / MLP блоков трансформеров, оптимизированная под системный кэш Apple Silicon (SLC).
- **Чистый GPU Muon и оптимизаторы (v0.6.0)**: Полностью GPU-резидентный кернел 5-го порядка Ньютона-Шульца (`metal_kan_newton_schulz5_gpu`), исполняющий все 5 итераций в едином командном буфере без обращений к CPU BLAS. Оптимизаторы (AdamW, SGD, Lion, RMSprop) получили адаптивные тредгруппы на 1024 потока.
- **Слитый обратный проход (v0.6.0)**: Потоковый backward-кернел (`metal_kan_cheby_backward_fused`) вычисляет градиенты весов и входов на лету в регистрах потоков без материализации промежуточного тензора $\Phi$ $[B \times (D_{in} \cdot K)]$ в глобальной памяти VRAM (экономя 32+ МБ трафика памяти за шаг).
- **Суб-4-битное квантование (v0.6.0)**: 1.58-битный Ternary KAN (`to_ternary`) и 2-битный кодобук KAN (`to_int2`) с безветвевой распаковкой в регистрах MSL.
- **Стабилизация FP16 (v0.6.0)**: Рекуррентные вычисления полиномов в регистрах FP32 с инструкцией `fma` в шейдерах Чебышёва и Якоби, устраняющие катастрофическую потерю точности на границах $\pm 1$.
- **Аппаратный движок половинной точности FP16**: Переключение любого слоя или сети в FP16 через `.half()` с ускорением до 3.2x на тензорных ядрах Apple Silicon и автоматической диспетчеризацией типов.
- **Прямые ворп-кернелы MSL 3.0 `simdgroup_matrix`**: Вычисления GEMM прямо в регистрах ворпа в обход накладных расходов MPS для малых и средних батчей ($B \le 256$).
- **Асинхронная кольцевая GPU-конвейеризация**: Двойная/тройная буферизация команд (`async_stream`, `set_async`, `sync`) снижает задержку диспетчеризации с хоста с 0.35 мс до 0.0065 мс.
- **Zero-Allocation GPU-конвейер**: Вычисление базисов выполняется на лету в аппаратных регистрах потоков без промежуточных буферов VRAM.
- **Zero-Copy взаимодействие с хостом**: Прямое связывание NumPy-массивов через `newBufferWithBytesNoCopy` в объединённой памяти macOS.
- **GPU-конвейеризация (`pipeline=True`)**: Многослойная сеть исполняется за один вызов командного буфера GPU с пинг-понг буферами (без задержек синхронизации CPU).
- **Набор квантования**: Блочно-аффинное INT8, упакованное INT4, 2-битное INT2 и 1.58-битное Ternary сжатие весов (`to_int8`, `to_int4`, `to_int2`, `to_ternary`).
- **Структурный прунинг и компактизация**: Оценка важности нейронов и физическое удаление неактивных узлов (`compact_kan`).
- **Символьная регрессия и экспорт в C99**: Преобразование обученного KAN в аналитические формулы и компилируемый C-заголовок (`export_c`).
- **Чистый Metal-бэкенд**: Полная независимость от PyTorch, MLX и LibTorch.

## Поддерживаемые архитектуры

| Архитектура | Математический базис | Аппаратная реализация | Рекомендуемое применение |
|---|---|---|---|
| **`ChebyKAN`** | Полиномы Чебышёва ($T_k$) | 3-термная рекуррентность в регистрах | Гладкие функции, физика |
| **`FastKAN`** | Гауссовы RBF | Общие центры в SRAM тредгруппы | Универсальная аппроксимация |
| **`ReLUKAN`** | Piecewise-linear (Tent) | Hardware clamp, 0 трансцендентных операций | Минимальная задержка, edge-инференс |
| **`WavKAN`** | Вейвлеты (Mexican Hat, Morlet, DOG) | Локализованные вейвлеты в регистрах | Временные ряды, аудио |
| **`FourierKAN`** | Тригонометрия ($\cos, \sin$) | Векторные SIMD-вычисления | Периодические сигналы, PINNs |
| **`JacobiKAN`** | Полиномы Якоби $(\alpha, \beta)$ | Обобщенная ортогональная рекуррентность | Краевые задачи, дифференциальные уравнения |
| **`RationalKAN`** | Рациональные дроби Паде ($P/Q$) | Отношение полиномов Чебышёва | Полюса, пограничные слои, кинетика |
| **`BSplineKAN`** | B-сплайны де Боора | Поиск интервалов и рекуррентный спуск | Классический KAN, интерпретируемость |
| **`MultKAN`** | Узлы умножения ($u \cdot v$) | Fused сплайны + каналы умножения | Аналитическая регрессия, законы физики |
| **`LowRankKAN`** | Низкоранговая факторизация | Bottleneck-проекция | Глубокие и широкие сети |

## Быстрый старт

```python
import numpy as np
from metal_kans import (
    ChebyKAN, FastKAN, ReLUKAN, WavKAN, FourierKAN, JacobiKAN, RationalKAN, BSplineKAN,
    MetalKAN, to_int8, compact_kan, to_symbolic
)

# 1. Создание многослойной сети с конвейерным исполнением на GPU
model = MetalKAN(
    layers_hidden=[4, 32, 16, 2], 
    basis_type="cheby", 
    degree=4, 
    pipeline=True
)

x = np.random.uniform(-1.0, 1.0, (1024, 4)).astype(np.float32)
y = model(x)
print("Форма выхода:", y.shape)  # (1024, 2)

# 2. Аппаратное ускорение в половинной точности FP16 (v0.4.0)
model.half()
x_half = x.astype(np.float16)
y_half = model(x_half)  # Вычисляется на half-шейдерах MSL

# 3. Асинхронный потоковый конвейер (v0.4.0)
stream_batches = [np.random.randn(256, 4).astype(np.float32) for _ in range(20)]
stream_outputs = model.async_stream(stream_batches)  # Без блокировок CPU между батчами

# 4. Монолитное обучение напрямую на Metal GPU (v0.5.1)
from metal_kans import BSplineKAN, FastKAN, ChebyKAN, MetalKAN, AdamW, Muon, Lion, RMSprop, Adam, SGD, build_train_step, checkpoint_kan

model = BSplineKAN(64, 64, grid_size=5)
opt = AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

# Вариант A: Монолитный фьюзинг шага обучения (Forward + MSE Loss + Backward + AdamW в ОДНОМ GPU CommandBuffer)
train_step = build_train_step(model, opt)
for epoch in range(100):
    train_step(x, target)  # До 1.94x быстрее Apple MLX и до 19.6x быстрее PyTorch MPS

# Вариант B: Модульный цикл обучения с любым оптимизатором (Muon, Lion, AdamW и др.)
for epoch in range(100):
    pred = model(x)
    loss_grad = 2.0 * (pred - target) / len(x)  # Градиент MSE dL/dy
    model.backward(loss_grad)                   # Аналитические производные базиса на Metal GPU
    opt.step()                                  # Шаг Metal-ускоренного оптимизатора
    model.zero_grad()

# 5. Activation Checkpointing (экономия 70-80% VRAM)
ckpt_model = checkpoint_kan(model)  # Сохраняет только входы x, пересчитывая базис на backward

# 6. Квантование весов в INT8 (4-кратное сжатие памяти)
to_int8(model)

# 7. Структурный прунинг и физическая компактизация сети
compact_model = compact_kan(model, threshold=1e-3)

# 8. Символьная регрессия и экспорт в C99
sym = to_symbolic(compact_model, sample_points=100)
sym.export_c("kan_model.h", func_name="kan_predict")

```

*За счет чего metal-KANs опережает MLX при обучении?* Классические фреймворки циклически синхронизируют процессор и видеокарту при вычислении лосса и обновлении оптимизатора через фрагментированные кернелы. `metal-KANs` сшивает весь шаг обучения (Forward $\to$ Loss $\to$ Backward $\to$ Adam) в **единый монолитный GPU CommandBuffer**, исключая пузыри простоя CPU и пересчитывая производные базисов прямо в регистрах ALU.

## Экспорт в чистый C

Обученная модель KAN экспортируется в автономный заголовочный файл C99 без каких-либо внешних библиотек:

```c
#include "kan_model.h"

int main() {
    float x[4] = {0.2f, -0.5f, 0.8f, 0.1f};
    float y[2];
    kan_predict(x, y);
    printf("Предсказание: %f, %f\n", y[0], y[1]);
    return 0;
}
```
