# metal-KANs

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![Apple Silicon](https://img.shields.io/badge/Apple%20Silicon-M1%20--%20M4%20Metal%20GPU-purple.svg)](https://developer.apple.com/metal/)
[![Metal Shading Language](https://img.shields.io/badge/MSL-3.0+-orange.svg)](https://developer.apple.com/metal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**metal-KANs** — высокопроизводительная библиотека сетей Колмогорова — Арнольда (**Kolmogorov-Arnold Networks, KAN**) на чистом **Metal Shading Language (MSL)** для Apple Silicon (M1 / M2 / M3 / M4 / Pro / Max / Ultra) с удобной Python / NumPy оберткой.

В отличие от стандартных фреймворков глубокого обучения, материализующих трехмерные базисные тензоры в видеопамяти, **metal-KANs вычисляет базис и линейную проекцию GEMM непосредственно в регистрах потоков GPU и разделяемой памяти тредгруппы (SRAM)**.

---

## Ключевые возможности

- **Полный набор из 10 современных архитектур KAN**:
  - `ChebyKAN`: Полиномы Чебышёва 1-го рода (3-термная рекуррентность в регистрах).
  - `FastKAN`: Гауссовы радиальные базисные функции (RBF) с общими центрами.
  - `ReLUKAN`: Кусочно-линейные палаточные функции (ноль трансцендентных операций).
  - `WavKAN`: Непрерывные вейвлеты (Mexican Hat, Morlet, DOG) для частотно-временной локализации.
  - `FourierKAN`: Гармонические тригонометрические ряды ($\cos, \sin$) для периодических процессов и PINN.
  - `JacobiKAN`: Ортогональные полиномы Якоби с весовыми коэффициентами $(\alpha, \beta)$.
  - `RationalKAN`: Дроби Паде-Чебышёва ($P(x) / (1 + |Q(x)|)$) для моделирования полюсов и сингулярностей.
  - `BSplineKAN` / `KAN`: Классический алгоритм Кокса — де Боора для кубических B-сплайнов.
  - `MultKAN`: KAN 2.0 с узлами умножения ($u \cdot v$) для точного моделирования законов сохранения.
  - `LowRankKAN`: Факторизованная проекция (LoRA / Bottleneck) со сжатием параметров до 10 раз.
- **Zero-Allocation GPU-конвейер**: Вычисление базисов выполняется на лету в аппаратных регистрах потоков без промежуточных буферов VRAM.
- **Zero-Copy взаимодействие с хостом**: Прямое связывание NumPy-массивов через `newBufferWithBytesNoCopy` в объединённой памяти macOS.
- **GPU-конвейеризация (`pipeline=True`)**: Многослойная сеть исполняется за один вызов командного буфера GPU с пинг-понг буферами (без задержек синхронизации CPU).
- **Квантование INT8 и INT4**: Блочно-аффинное сжатие весов (`to_int8`, `to_int4`).
- **Структурный прунинг и компактизация**: Оценка важности нейронов и физическое удаление неактивных узлов (`compact_kan`).
- **Символьная регрессия и экспорт в C99**: Преобразование обученного KAN в аналитические формулы и компилируемый C-заголовок (`export_c`).
- **Чистый Metal-бэкенд**: Полная независимость от PyTorch, MLX и LibTorch.

## Поддерживаемые архитектуры

| Архитектура | Математический базис | Аппаратная реализация | Рекомендуемое применение |
|---|---|---|---|
| **`ChebyKAN`** | Полиномы Чебышёва ($T_k$) | 3-термная рекуррентность в регистрах | Гладкие функции, физика |
| **`FastKAN`** | Гауссовы RBF | Общие центры в SRAM тредгруппы | Универсальная аппроксимация |
| **`ReLUKAN`** | Piecewise-linear (Tent) | Hardware clamp, 0 трансцендентных операций | Минимальная задержка, edge-инференс |
| **`WavKAN`** | Вейвлеты (Mexican Hat, Morlet, DOG) | Локализованные вейвлеты в регистрах | Временные ряды, аудио |
| **`FourierKAN`** | Тригонометрия ($\cos, \sin$) | Векторные SIMD-вычисления | Периодические сигналы, PINNs |
| **`JacobiKAN`** | Полиномы Якоби $(\alpha, \beta)$ | Обобщенная ортогональная рекуррентность | Краевые задачи, дифференциальные уравнения |
| **`RationalKAN`** | Рациональные дроби Паде ($P/Q$) | Отношение полиномов Чебышёва | Полюса, пограничные слои, кинетика |
| **`BSplineKAN`** | B-сплайны де Боора | Поиск интервалов и рекуррентный спуск | Классический KAN, интерпретируемость |
| **`MultKAN`** | Узлы умножения ($u \cdot v$) | Fused сплайны + каналы умножения | Аналитическая регрессия, законы физики |
| **`LowRankKAN`** | Низкоранговая факторизация | Bottleneck-проекция | Глубокие и широкие сети |

## Быстрый старт

```python
import numpy as np
from metal_kans import (
    ChebyKAN, FastKAN, ReLUKAN, WavKAN, FourierKAN, JacobiKAN, RationalKAN, BSplineKAN,
    MetalKAN, to_int8, compact_kan, to_symbolic
)

# 1. Создание многослойной сети с конвейерным исполнением на GPU
model = MetalKAN(
    layers_hidden=[4, 32, 16, 2], 
    basis_type="cheby", 
    degree=4, 
    pipeline=True
)

x = np.random.uniform(-1.0, 1.0, (1024, 4)).astype(np.float32)
y = model(x)
print("Форма выхода:", y.shape)  # (1024, 2)

# 2. Квантование весов в INT8 (4-кратное сжатие памяти)
to_int8(model)

# 3. Структурный прунинг и физическая компактизация сети
compact_model = compact_kan(model, threshold=1e-3)

# 4. Символьная регрессия и экспорт в C99
sym = to_symbolic(compact_model, sample_points=100)
sym.export_c("kan_model.h", func_name="kan_predict")
```

## Экспорт в чистый C

Обученная модель KAN экспортируется в автономный заголовочный файл C99 без каких-либо внешних библиотек:

```c
#include "kan_model.h"

int main() {
    float x[4] = {0.2f, -0.5f, 0.8f, 0.1f};
    float y[2];
    kan_predict(x, y);
    printf("Предсказание: %f, %f\n", y[0], y[1]);
    return 0;
}
```
