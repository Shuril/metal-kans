# metal-KANs

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![Apple Silicon](https://img.shields.io/badge/Apple%20Silicon-M1%20--%20M4%20Metal%20GPU-purple.svg)](https://developer.apple.com/metal/)
[![Metal Shading Language](https://img.shields.io/badge/MSL-3.0+-orange.svg)](https://developer.apple.com/metal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**metal-KANs** — библиотека сетей Колмогорова — Арнольда (**Kolmogorov-Arnold Networks, KAN**) на чистом **Metal Shading Language (MSL)** для Apple Silicon (M1 / M2 / M3 / M4 / Pro / Max / Ultra) с удобной и быстрой оберткой на Python (NumPy).

В отличие от стандартных фреймворков глубокого обучения, которые сначала материализуют трехмерный тензор базисных функций в видеопамяти, а затем вызывают матричное умножение, **metal-KANs объединяет (fuse) вычисление базиса и линейную проекцию GEMM непосредственно в регистрах потоков GPU и разделяемой памяти тредгруппы (SRAM)**.

---

## Ключевые преимущества

- **Нулевые промежуточные аллокации видеопамяти**: Базисные функции (полиномы Чебышёва, гауссовы RBF, кусочно-линейные палатки) вычисляются на лету прямо в регистрах потоков GPU и сразу аккумулируются в выходную матрицу за 1 проход.
- **Zero-Copy взаимодействие с хостом**: Прямая привязка NumPy-массивов к конвейеру Metal через указатели объединённой памяти macOS (`newBufferWithBytesNoCopy`). Никаких операций копирования данных (`memcpy`) между CPU и GPU.
- **Аппаратные оптимизации под архитектуру Apple GPU**:
  - **Тайлинг в разделяемой памяти (SRAM)**: совместная загрузка блоков $32 \times 32$ для входов и весовых матриц.
  - **2D-блокировка регистров**: $2 \times 2$ регистра на поток GPU для максимального параллелизма инструкций (ILP).
  - **Аппаратный матричный сопроцессор (`simdgroup_matrix`)**: поддержка выполнения операций 8x8 напрямую на матричных ядрах Apple Silicon.
- **Отсутствие тяжелых зависимостей**: Не требует PyTorch, MLX или LibTorch. Достаточно `numpy` и стандартного компилятора macOS Command Line Tools (`clang++`).
- **Производительность**: Пропускная способность до **11.6+ миллионов семплов в секунду** на базовом процессоре Apple M1.

## Поддерживаемые слои

| Слой | Базисная функция | Особенности кернела | Рекомендуемое применение |
|---|---|---|---|
| **`ChebyKAN`** | Полиномы Чебышёва ($T_k(x) = 2x T_{k-1} - T_{k-2}$) | Рекуррентное вычисление в регистрах | Гладкие функции, физическое моделирование |
| **`FastKAN`** | Гауссовы RBF ($\exp(-\frac{(x - \mu)^2}{2\sigma^2})$) | Быстрая векторная математика с общими центрами | Универсальная аппроксимация функций |
| **`ReLUKAN`** | Piecewise-linear (Tent, $\max(0, 1 - \frac{\|x - \mu\|}{h})$) | Ноль трансцендентных функций, аппаратный clamp | Низкая задержка, edge-инференс |
| **`MetalKAN`** | Последовательный многослойный контейнер | Конвейерное исполнение цепочки слоев на GPU | Глубокие архитектуры KAN |

## Быстрый старт

```python
import numpy as np
from metal_kans import ChebyKAN, FastKAN, ReLUKAN, MetalKAN

# 1. Одиночный слой ChebyKAN (in_features=64, out_features=32, степень=4)
layer = ChebyKAN(in_features=64, out_features=32, degree=4)

x = np.random.uniform(-1.0, 1.0, (1024, 64)).astype(np.float32)
y = layer(x)
print("Форма выхода:", y.shape)  # (1024, 32)

# 2. Многослойная сеть на чистом Metal
model = MetalKAN(
    layers_hidden=[64, 128, 64, 10], 
    basis_type="cheby", 
    degree=4
)
out = model(x)
print("Форма выхода сети:", out.shape)  # (1024, 10)

# 3. Встроенный бенчмарк задержки
latency_ms = layer.benchmark(x, warmup=10, iters=50)
throughput = len(x) / (latency_ms / 1000.0)
print(f"Задержка: {latency_ms:.3f} ms | Пропускная способность: {throughput:,.0f} семплов/с")
```

## Архитектура и структура шейдеров

В обычных фреймворках вычисление KAN разбито на два независимых шага:
$$\text{Вход: } [B, D_{\text{in}}] \xrightarrow{\text{Генерация базиса}} \text{Тензор: } [B, D_{\text{in}}, K] \xrightarrow{\text{Линейный GEMM}} \text{Выход: } [B, D_{\text{out}}]$$

На больших батчах ($B \ge 1024$) промежуточный тензор занимает мегабайты памяти, перегружая шину памяти и требуя лишней синхронизации ядер GPU.

**metal-KANs полностью исключает промежуточный тензор:**
1. **Коллаборативная загрузка тайлов**: потоки тредгруппы синхронно читают блоки $32 \times 8$ входов и весов в быструю SRAM-память тредгруппы.
2. **Вычисление базиса на лету**: каждый поток вычисляет рекуррентные полиномы или гауссианы непосредственно в аппаратных регистрах.
3. **Регистровая 2D-аккумуляция**: четыре независимых регистра аккумулятора обновляются параллельно, маскируя арифметические задержки конвейера GPU.
